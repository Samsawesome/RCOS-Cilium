DNS:
DNS (domain name system) is the system that translates human readable addresses (urls) into ip addresses. It exists as a distributed database, meaning it works through a hierarchy of servers. 
DNS protocal:
When a url is searched for, the computer tries to find the IP address. First it checks the local cahce, checking if it already knows the IP for the website you entered. Next, the url gets sent to a DNS resolver to find the IP. The resolver sends it to a root DNS server, which points to the TLD server (either .com server, .org server, .net server, etc). TLD server directs to the authoriative nameserver for the url, which contains all header urls (cse.dtu.org, ece.dtu.org, mec.dtu.org, etc). From this, it is able to find the url, returns its corrisponding IP, and the user's machine connects to the website (IP). 
Goal of DNS is accuracy (must be 100% accurate, rewriten user to wrong IP could be catastrophic) and speed.
L7:
L7 stands for for Layer 7 Protocol Visibility, and they offer control over application-layer traffic. In the model of communication process between users online, there are 7 layers. Layer 1 is the physical layer (cables, radio waves), layer 2 is data link (ethernet, wifi), layer 3 is network layer (IP, routers), layer 4 is transport (TCP), layer 5 is session layer (APIs), layer 6 is presentation layer (PNG, ASCII), and layer 7 is application layer (HTTP/HTTPS). Layer 7 network policies control traffic on application level data, such as URLs, HTTP methods, headers, and domains. This layer of security can block malicious API calls, enforce compliance rules (only allowing users on safe websites), and protection against application layer attacks like SQL injection.
